# TODO: fix the license declaration for the card artwork

Found in the 2026-09-24 fleet audit. Left as a note instead of a fix because this repo and Solitaire are mid-change.

## The problem

`package.json` declares `"license": "MIT"`, but most of the artwork this package ships is derived from
[SVG-cards](https://github.com/htdebeer/SVG-cards) and licensed under LGPL-2.1:

- `src/artwork/LICENSE` is the full LGPL-2.1 text.
- `src/artwork/NOTICE.md` credits David Bellot (2005) and Huub de Beer (2016, 2017) and says the notice
  must be kept with any distributed copy of the artwork.
- `src/artwork/court.ts` and `src/artwork/types.ts` carry LGPL-2.1 headers.
- The generated art is compiled into `dist/index.js` and `dist/index.mjs`, which carry no license text.
- The README never mentions the artwork license.

The notice files do reach npm, because `files` includes `src`. The problem is that the package-level
declaration says MIT, which is what npm, license scanners and anyone reading package.json will see.

## To do

1. Change `license` in package.json to an SPDX expression covering both parts, for example
   `"(MIT AND LGPL-2.1-only)"`. Check whether upstream SVG-cards says "2.1 only" or "2.1 or later" and use
   `LGPL-2.1-or-later` if it is the latter.
2. Add a License section to the README: code is MIT, artwork under `src/artwork/` is LGPL-2.1 and derived
   from SVG-cards, with the same credits as NOTICE.md.
3. Consider copying `src/artwork/LICENSE` and `NOTICE.md` to the package root (e.g. `LICENSE-artwork.md`),
   so they show up on the npm page and next to package.json.
4. Fix stale paths:
   - `src/artwork/types.ts` line 3 points to `src/components/cards/artwork/NOTICE.md`. The file is
     `src/artwork/NOTICE.md`.
   - `NOTICE.md` describes the decorated style as living in `artwork/decorated/`. The folder is now
     `src/artwork/decoratedCustom/`.
5. The new, still uncommitted `src/artwork/courtBitmaps/` PNGs are generated by
   `scripts/generate-court-bitmaps.mjs`. If they are rendered from SVG-cards, add them to NOTICE.md too.
6. Apps that ship this art in store builds (Solitaire, EgyptianRatscrew) should show the attribution
   in-app, for example on an about or credits screen, as NOTICE.md already asks.
7. Optional: check whether LGPL-2.1's other terms, beyond keeping the notice, matter for art bundled
   into an app binary. This note is not legal advice.
